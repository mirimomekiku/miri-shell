## 1. Executive Summary & Architecture Overview

`setup-launcher` is a graphical developer onboarding wizard engineered for Fedora Linux and Hyprland. It enables engineers to select and install all required web, backend, mobile, AI agent, and terminal tools in one automated flow with live streaming logs, system binary detection (`[ Installed ]` badges), and dynamic progress tracking.

```text
│   ├── SetupWindow.tsx     # Window container, view switcher, keyboard accelerators

│
└── service/                # Business Logic & Process Execution
    ├── catalog.ts          # Complete catalog of packages, categories, and commands
    ├── installer.ts        # Execution engine, log streamer, and reactive state
    └── icons.ts            # 2,069 authentic Lucide icon Unicode font mappings
```
