## 1. Executive Summary & Architecture Overview

`file-explorer` is a high-performance desktop file manager engineered with **Astal GTK3**. It provides instantaneous directory navigation via synchronous `Gio.File` enumeration, bounded resizable paned layout (`Gtk.Paned` clamped between `140px` and `320px`), persistent sidebar bookmarks, semi-translucent hidden file distinction (`opacity: 0.65`), rich semantic file category colors, and deep IDE/Terminal integration.


## 3. Semantic File Category & Hidden File Styling

| Category | File Extensions | Lucide Glyph | Accent Color |
|---|---|---|---|
| **Folder** | Directories, `.git`, `src/`, `dist/` | `folder`, `folder-git`, `folder-code` | `#58a6ff` (Vivid Blue) |
| **Code** | `.ts`, `.tsx`, `.js`, `.py`, `.rs`, `.go`, `.json`, `.yaml` | `file-code` | `#a6e3a1` (Mint Green) |
| **Documents** | `.pdf`, `.doc`, `.docx`, `.odt`, `.rtf`, `.txt`, `.md` | `file-text` | `#89dceb` (Sky Blue) |
| **Spreadsheets**| `.xlsx`, `.csv`, `.tsv`, `.ods` | `file-spreadsheet` | `#94e2d5` (Teal) |
| **Images** | `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.gif` | `image` | `#f9e2af` (Warm Sand) |
| **Audio** | `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a` | `music` | `#f38ba8` (Rosewater Coral) |
| **Video** | `.mp4`, `.mkv`, `.webm`, `.avi`, `.mov` | `video` | `#cba6f7` (Lavender Purple) |
| **Archives** | `.zip`, `.tar.gz`, `.xz`, `.7z`, `.deb`, `.rpm` | `archive` | `#fab387` (Peach Orange) |
| **Binaries** | `.bin`, `.appimage`, `.exe`, `.sh` | `terminal` | `#eba0ac` (Crimson) |

**Hidden Dotfiles (`.is-hidden`)**: Rendered with `opacity: 0.65` and dimmed text (`#a6adc8`), brightening smoothly to `opacity: 0.95` on hover.
