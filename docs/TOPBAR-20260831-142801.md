## 1. Executive Summary & Architecture Overview

`top-bar` is a standalone, floating pill top bar and drop-down ecosystem designed for Wayland compositors (specifically **Hyprland**). It provides hardware controls, workspaces, audio management, Wi-Fi networking, Bluetooth device pairing, screen recording/screenshots, and a live FreeDesktop notification center.

### Core Architectural Principles
1. **Isolated Modular Directory**: All top bar components, services, styles, and configurations reside self-contained within `./top-bar/`.
2. **Centered Floating Pill Design**: The bar floats centered at the top of the monitor (`[ 18:56 ] [ 󰕾 54% ] [ (1) (2) [3] 4 5 ] [ 󰤨 SSID ] [ 󰁹 48% ]`).
3. **Exclusive Slide-Down Dropdowns**:
   - **Clicking Time/Clock** → Slides down the **Control Center** (Quick Toggles, Bluetooth Manager, Brightness Slider, Notifications, Utilities).
   - **Clicking Audio Pill** → Slides down the **Media & Volume Popup** (Album art, scrubber, play/pause, volume slider).
   - **Clicking Wi-Fi Pill** → Slides down the **Wi-Fi Dropdown** (Connected network pill, available networks with signal strength, password prompt).
4. **0ms Latency Optimistic State**: Volume and screen brightness update instantly in-memory for smooth 60fps slider drags, while hardware commands (`wpctl`, `brightnessctl`) are asynchronously debounced in the background.
5. **Live DBus Notification Subsystem**: Implements the FreeDesktop `org.freedesktop.Notifications` DBus server and stream monitor to capture live notifications from desktop applications.
6. **Flat Shadowless Aesthetic**: Minimalist, clean UI with zero drop shadows (`box-shadow: none;`).
7. **Lucide Icons Font System**: All glyphs across widgets and services use the official **Lucide** icon font.

## 3. Component Breakdown

### 3.1 Main Floating Bar (`widget/Bar.tsx`)
- **Structure**: A fixed-height floating container anchored to the top of the monitor using `Astal.WindowAnchor.TOP`.
- **Top Pill (`.PillBar`)**: A horizontal box with rounded pill radius (`9999px`), dark charcoal background (`#18191c`), and subtle border. Contains:
  1. `<Clock />`
  2. `<Audio />`
  3. `<Workspaces />`
  4. `<Network />`
  5. `<Battery />`
- **Slide-Down Revealers**: Houses three separate `Gtk.Revealer` instances (`transitionType={Gtk.RevealerTransitionType.SLIDE_DOWN}`):
  - Control Center Revealer (`revealChild={ControlCenter.isOpen}`)
  - Media Player Revealer (`revealChild={Media.isOpen}`)
  - Wi-Fi Menu Revealer (`revealChild={Network.isOpen}`)
- **Escape Key Handling**: Added a global key press event listener so pressing `Escape` instantly dismisses all active dropdowns.

---

### 3.2 Time / Clock Widget (`widget/Clock.tsx`)
- Polls the system time every 1,000ms.
- Displays `HH:mm` format (e.g. `18:56`).
- **Interaction**: Clicking toggles the **Control Center** and closes other popups.

---

### 3.3 Audio Indicator Widget (`widget/Audio.tsx`)
- Displays the current volume level (`󰕾 54%`) and mute state (`󰝟`).
- **Scroll Support**: Scrolling up or down over the widget adjusts volume by ±5% in real time.
- **Interaction**: Clicking toggles the **Media & Volume Popup**.

---

### 3.4 Workspaces Widget (`widget/Workspaces.tsx`)
- Integrates with `AstalHyprland`.
- Renders workspaces 1 through 5:
  - Occupied workspaces: shown in parentheses `(1)`.
  - Focused / Active workspace: highlighted in a bright active pill `[3]`.
  - Empty workspaces: muted number `4 5`.
- **Interaction**: Clicking any workspace number triggers `hyprland.dispatch("workspace", id)`.

---

### 3.5 Wi-Fi Indicator Widget (`widget/Network.tsx`)
- Displays current Wi-Fi icon (`wifi` / `wifi-off`) and active network SSID.
- Automatically abbreviates lengthy network names to fit the pill.
- **Interaction**: Clicking toggles the **Wi-Fi Manager Dropdown**.

---

### 3.6 Battery Indicator Widget (`widget/Battery.tsx`)
- Reads `/sys/class/power_supply/BAT0/status` and `capacity`.
- **Accurate Charging State**: Checks `status === "charging"` to avoid false charging indications caused by substring matches on `"discharging"`.
- Displays dynamic Lucide battery glyphs: `battery-full`, `battery-medium`, `battery-low`, `battery-warning`, and `battery-charging`.

---

### 3.7 Control Center Dropdown (`widget/ControlCenter.tsx`)
A multi-functional utility card providing quick settings:
1. **Quick Toggles Row**:
   - **Wi-Fi Toggle**: Displays current SSID and connection state; clicking toggles the Wi-Fi menu.
   - **Do Not Disturb (DND)**: Toggles notification silencing with Lucide `bell` / `bell-off`.
   - **Timer Cycle**: Cycles through idle timers (`1m`, `5m`, `10m`, `15m`, `30m`).
   - **Bluetooth Toggle**: Expands the Bluetooth device management panel.
2. **Expandable Bluetooth Device Panel**:
   - Subheader: `"Bluetooth"` title, `Visible as "<controller_name>"`, rescan button (`rotate-cw`), and power toggle switch (`power`).
   - Devices List:
     - **Connected Device**: Solid vibrant blue pill card (`#437bf6`) with `bluetooth-connected` icon and `"Connected"` subtitle. Clicking disconnects.
     - **Paired / Saved Devices**: Dark pill card with `link-2` icon and `"Paired • right-click to forget"`. Left click connects; right click forgets device via `bluetoothctl remove`.
     - **Available Devices**: Discovered nearby devices. Clicking pairs and connects.
3. **Screen Brightness Slider**:
   - 0ms latency slider with live percentage readout and Lucide `sun` / `sun-medium` / `sun-dim` / `moon` glyphs.
4. **Notifications Center**:
   - Header: Live counter (`"Notifications (3)"`) and pill-style `"Clear all"` button.
   - Expanded height scrollable container (`min-height: 180px`).
   - Live notification cards with app icon, summary title, timestamp (`"16:25"`), dismiss button (`x`), and multi-line body text.
5. **Quick Utilities Bar**:
   - Circular, right-aligned action buttons with 9999px border radius:
     - **Screenshot Button (`camera`)**: Takes interactive region screenshot, saves to `~/Pictures/Screenshots`, and copies to clipboard.
     - **Screen Recording Button (`video` / `radio`)**: Toggles screen recording via `wf-recorder` / `wl-screenrec` / `ffmpeg` with live red recording state.
     - **Settings Button (`settings`)**: Opens system configuration app (`gnome-control-center` / `systemsettings`).

---

### 3.8 Media Player & Volume Popup (`widget/MediaPopup.tsx`)
- **Album Art**: 48px square preview with smooth border radius, loading cover art URL from MPRIS or fallback Lucide `music` glyph.
- **Track Details**: Song title and artist name with ellipsis truncation.
- **Scrubber Bar**: Real-time position tracking (`0:45` / `3:12`) with draggable progress slider.
- **Playback Controls**: Play / Pause toggle button (`play` / `pause`).
- **Volume Slider**: Real-time 0ms volume slider with mute toggle button and percentage readout.

---

### 3.9 Wi-Fi Manager Dropdown (`widget/NetworkMenu.tsx`)
- **Header**: `"Wi-Fi"` bold title and discovery rescan button (`rotate-cw`).
- **Pill Items (Matching Reference Design)**:
  - **Connected Network**: Solid vibrant blue card (`#437bf6`) with `lock` or `wifi` icon, bold SSID, and `"Connected"` subtitle. Clicking disconnects.
  - **Available Networks**: Dark pill cards (`#232530`) with lock icon, bold SSID, and signal bar indicators (`"Excellent"`, `"Good"`, `"Fair"`, `"Weak"`).
  - **Password Authentication**: Clicking an unsaved secured network smoothly slides open an inline password input field with **Connect** and **Cancel (`x`)** buttons.
  - **BSSID & MAC Filtering**: Filters out raw MAC addresses and empty hidden network SSIDs.

## 5. Reactive GJS/GNIM State Guidelines

When creating dynamic widget lists in `gnim` for GTK3:
- **Rule**: Never pass `{createComputed(() => <Widget />)}` as a direct JSX child of a container, as `gnim` will stringify the accessor to text `Accessor { ... }`.
- **Pattern**: Use the `$={(self) => ...}` container lifecycle hook:
  ```tsx
  <box
    orientation={Gtk.Orientation.VERTICAL}
    spacing={4}
    $={(self) => {
      const render = () => {
        self.get_children().forEach((ch) => ch.destroy())
        const items = MyService.data()
        for (const item of items) {
          self.add(<button ... />)
        }
        self.show_all()
      }
      render()
      MyService.data.subscribe(render)
    }}
  />
  ```

## 6. How to Run, Bundle, and Deploy

### Prerequisites
- Fedora / Arch Linux with Hyprland or Wayland compositor.
- Installed binaries: `brightnessctl`, `wpctl` (or `pactl`), `bluetoothctl`, `nmcli`, `grim`, `slurp`, `wl-copy`.
- Astal typelibs installed in `/usr/local/lib64/girepository-1.0` or `/usr/lib64/girepository-1.0`.

### Running in Development Mode
```bash
cd /home/mirimomekiku/Projects/miri-shell
npm run dev
```

### Bundling for Production
```bash
GI_TYPELIB_PATH="/usr/local/lib64/girepository-1.0:/usr/local/lib/girepository-1.0:${GI_TYPELIB_PATH:-}" \
LD_LIBRARY_PATH="/usr/local/lib64:/usr/local/lib:${LD_LIBRARY_PATH:-}" \
ags bundle top-bar/app.ts dist/miri-topbar
```

### Autostarting with Hyprland
Add the following to `~/.config/hypr/hyprland.conf`:
```ini
exec-once = ags run /home/mirimomekiku/Projects/miri-shell/top-bar/app.ts
```
