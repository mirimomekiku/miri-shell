## 1. Executive Summary & Architecture Overview

`top-bar` is a floating, pill-style status bar and control center suite designed for Hyprland and Wayland on Fedora Linux. It delivers real-time system monitoring, responsive workspace switching, volume/media management, network configuration, and an extensible Control Center popup with zero memory leaks.

### Core Architectural Highlights
1. **Layer-Shell Floating Pill UI**: Anchored to `TOP` with `Astal.Exclusivity.EXCLUSIVE` and a transparent root window, rendering a centered `#18191c` pill (`border-radius: 9999px`).
2. **TrueType Font Segregation**: Strict separation between typography (`"MesloLGS Nerd Font"`, `"JetBrains Mono"`, `"Inter"`) and icon glyphs (`"lucide"`) to prevent character glyph collision.
3. **Reactive State Binding (`gnim`)**: Leverages `createState`, `createComputed`, and `createPoll` for real-time reactive updates across brightness, network, battery, hyprland workspaces, and audio.
4. **Mutually Exclusive Slide-Down Panels**: Dedicated `Gtk.Revealer` animation containers for **Media & Sound**, **Control Center**, and **Wi-Fi Menu**, ensuring only one active dropdown opens at any time.
5. **Interactive Tooltips**: Rich hover tooltips providing detailed contextual metrics (full weekday date, volume percentage with scroll instructions, SSID & signal strength, battery status).

## 2. Directory & Component Hierarchy

```text
miri-shell/top-bar/
├── app.ts                  # Astal entry point with BarWindow lifecycle
├── style.scss              # GTK3 SCSS stylesheet (Impeccable Edition)
├── package.json            # Scripts: dev, bundle, quit
├── tsconfig.json           # TypeScript configuration
├── env.d.ts                # TypeScript ambient module definitions
│
├── widget/                 # UI Components (JSX / Astal GTK3)
│   ├── Bar.tsx             # Root floating window, key listeners, revealer containers
│   ├── Clock.tsx           # Digital time label with full date tooltip
│   ├── Audio.tsx           # Audio volume percentage, scroll-wheel volume adjustment
│   ├── Workspaces.tsx      # Hyprland active/occupied workspace pills (1 2 3 4 5)
│   ├── Network.tsx         # Wi-Fi status widget with dynamic signal strength
│   ├── Battery.tsx         # Battery percentage, charging icon, and click-to-control
│   ├── ControlCenter.tsx   # Quick toggles (Wi-Fi, DND, Timer, Bluetooth), brightness/volume sliders, notifications, utilities
│   ├── MediaPopup.tsx      # MPRIS player card with album art, scrubber, and playback controls
│   └── NetworkMenu.tsx     # Wi-Fi network scanner, connection manager, and password modal
│
└── service/                # Backend Services & D-Bus / CLI Pollers
    ├── audio.ts            # WirePlumber / PulseAudio volume and sink controller
    ├── battery.ts          # Linux /sys/class/power_supply/BAT0 poller
    ├── bluetooth.ts        # bluetoothctl device scanner and connection manager
    ├── brightness.ts       # brightnessctl backlight controller
    ├── capture.ts          # grimblast screenshot and screen recording utilities
    ├── controlcenter.ts    # DND, presentation timer, and window visibility state
    ├── hyprland.ts         # hyprctl client and workspace tracker
    ├── icons.ts            # 2,069 authentic Lucide icon Unicode font mappings
    ├── media.ts            # MPRIS playerctl metadata and playback controller
    ├── network.ts          # nmcli Wi-Fi scanner and network manager
    └── notifications.ts    # Freedesktop notification daemon poller
```
