## 1. Executive Summary & Architecture Overview

`file-explorer` is a high-performance, dark-themed, developer-first desktop file manager built using **Aylur's GTK (Astal / AGS)**. Designed specifically for Linux power users, developers, and Wayland/Hyprland setups (with full support for Fedora Workstation), it provides instantaneous directory browsing, expandable quick-access bookmarks, responsive grid and table views, categorical file type glyphs, hidden file styling, and deep IDE/Terminal integration.

### Core Architectural Principles
1. **Self-Contained Modular Structure**: All explorer UI components, services, and SCSS styling reside self-contained within `./file-explorer/`.
2. **Sub-Millisecond Synchronous Directory Enumeration**: Employs synchronous `Gio.File.enumerate_children()` to instantly read folder contents and file metadata with 0ms async stream lag.
3. **Bounded Resizable Partitioning (`Gtk.Paned`)**: The left sidebar and right file viewport are linked via native GTK paned partitioning, restricted between `140px` (min) and `320px` (max) to prevent viewport collapse or overextension.
4. **Persistent Pinned Bookmarks**: Allows pinning/unpinning folders from right-click context menus with state persisted to `~/.config/miri-shell/pinned-folders.json`.
5. **Zero Memory Leaks (`createRoot` Scopes)**: All dynamic widget updates (`$={(self) => ...}`) are executed inside `createRoot((dispose) => ...)` lifecycles, guaranteeing proper signal cleanup without GJS tracking warnings.
6. **Multi-Desktop & Fedora Native**: Features fallback terminal launchers (Ptyxis, Foot, Alacritty, Kitty, GNOME Terminal) and multi-clipboard handlers (`wl-copy`, `xclip`, `xsel`).
7. **Impeccable UI/UX & Top-Bar Parity**: 100% color-synchronized with `miri-shell/top-bar` (`#18191c` charcoal base, `#22242e` cards, `#437bf6` accents, and shadowless flat surfaces).

## 3. Detailed Component Breakdown

### 3.1 Main Window (`widget/Window.tsx`)
- **Root Window (`window.ExplorerWindow`)**: Dimensions `960x620` with dark charcoal styling (`#18191c`).
- **Resizable Body (`Gtk.Paned`)**:
  - Implements `new Gtk.Paned({ orientation: Gtk.Orientation.HORIZONTAL, position: 200 })`.
  - Connects to `notify::position` signal to clamp divider position between `140px` and `320px`.
  - Left pane (`pack1`): `<Sidebar />` (`resize=false`, `shrink=false`).
  - Right pane (`pack2`): `<FileView />` (`resize=true`, `shrink=false`).
- **Footer Status Bar (`.StatusBar`)**:
  - Item count and directory total size indicator (`24 items • 1.2 GB`).
  - Action feedback text for copy/pin actions (`Copied path to clipboard`).
  - Active path label with middle ellipsize (`.../Projects/miri-shell`) or active selection metadata badge.
- **Keyboard Accelerators**:
  - `Arrow Keys` (`↑`, `↓`, `←`, `→`): Navigate and select files.
  - `Enter` / `KP_Enter`: Open selected folder / launch file.
  - `Escape`: Clear search filter or deselect file.
  - `Ctrl + H`: Toggle hidden dotfiles.
  - `Ctrl + R` / `F5`: Force refresh directory.
  - `Alt + Left`: History Back.
  - `Alt + Right`: History Forward.
  - `Alt + Up` / `Backspace`: Navigate to Parent Directory.

---

### 3.2 Header Navigation Bar (`widget/Header.tsx`)
- **History Controls**:
  - Back (`arrow-left`), Forward (`arrow-right`), Up (`arrow-up`), Refresh (`rotate-cw`).
  - Automatic disabled opacity when history boundaries are reached.
- **Interactive Breadcrumbs Bar (`.breadcrumbs-scrollable`)**:
  - Horizontal dark pill (`#14151a`, `border-radius: 9999px`).
  - Intelligently collapses `$HOME` path into clean `~` root chip with a dedicated home icon.
  - Clicking any breadcrumb segment navigates directly to that parent folder.
- **Search Entry (`.search-box`)**:
  - Real-time text filtering against directory items with Lucide `search` icon.
  - Native `visible` binding on search clear button (`✕`) when text is typed.
- **Action Buttons**:
  - New Folder button (`folder-plus`).
  - Grid / List view toggle button (`layout-grid` / `list`).
  - Hidden files toggle (`eye` / `eye-off`).
  - Terminal launcher button (`terminal`).

---

### 3.3 Collapsible Sidebar (`widget/Sidebar.tsx`)
- **PINNED / QUICK ACCESS Section**:
  - Expand/collapse header button with Lucide `chevron-down` / `chevron-right` icon.
  - Pinned count pill badge (`.pinned-count-badge`).
  - Animated `Gtk.Revealer` (`transitionType=SLIDE_DOWN`).
  - Lists user-pinned directories with contextual folder icons.
  - Hovering reveals instant unpin button (`✕`).
  - Right-click brings up unpin and open in terminal options.
- **PLACES Section**:
  - Standard user shortcuts: **Home**, **Projects**, **Downloads**, **Documents**, **Pictures**, **Music**, **Videos**, and **Root System (`/`)**.
  - Active path highlighting (`.active` pill styling `#2b2f3e` with `#437bf6` accent).

---

### 3.4 File & Folder Content View (`widget/FileView.tsx`)
- **Dual View Modes**:
  1. **Grid View (`Gtk.FlowBox`)**:
     - Homogeneous square cards with 38px folder/file Lucide icons.
     - Filename wrapped and centered with maximum 14 characters per line.
     - Folder sizes are automatically omitted; file sizes displayed in subtle muted text.
  2. **List View (`Gtk.Box`)**:
     - Dense row layout with Name, Size, and Date Modified columns.
- **Robust Double-Click Navigation**:
  - Implements timestamp delta tracking (`now - lastClickTime < 450ms`) to guarantee 100% double-click detection across all Wayland compositors.
- **Hidden Dotfile Distinction (`.is-hidden`)**:
  - Hidden files and folders (e.g. `.git`, `.config`, `.env`, `.bashrc`) automatically receive `opacity: 0.65` and dimmed text (`#a6adc8`), smoothly brightening to `opacity: 0.95` on hover.
- **Developer Context Menu**:
  - **Open File / Open Folder**
  - **Open with Antigravity IDE** (`agy` / `antigravity`)
  - **Open with VS Code** (`code` / `codium`)
  - **Open in Terminal** (Ptyxis, Foot, Alacritty, Kitty, GNOME Terminal)
  - **Open in LazyGit** (for Git repositories)
  - **Pin to Sidebar / Unpin from Sidebar**
  - **Copy Full Path** (`wl-copy` / `xclip`)
  - **Move to Trash** (`Gio.File.trash_async`)

## 4. Backend Services & State Management

### 4.1 Filesystem Service (`service/fs.ts`)
- **Synchronous Enumerator**:
  ```ts
  const enumerator = dir.enumerate_children("standard::*,time::*", Gio.FileQueryInfoFlags.NONE, null)
  while ((info = enumerator.next_file(null)) !== null) { ... }
  ```
- **Reactive State Properties (`gnim`)**:
  - `currentPath`: Accessor for active directory.
  - `items`: Raw array of `FileItem` objects.
  - `filteredItems`: Computed array applying search filters, hidden file rules, and folder-first alphabetical sorting.
  - `pinned`: Pinned directories loaded from and saved to `~/.config/miri-shell/pinned-folders.json`.
  - `viewMode`: `"grid"` | `"list"`.
  - `showHidden`: Boolean toggle.
  - `totalDirectorySizeStr`: Computed formatted size of all visible files.

## 6. Build, Run & Standalone Deployment

### Running in Development
```bash
cd file-explorer
npm run dev
```

Or from repository root:
```bash
npm run dev:files
```

### Standalone Executable Binary
Bundle standalone JavaScript binary into `dist/miri-files`:
```bash
cd file-explorer
npm run bundle
```

### CLI Arguments Support
```bash
miri-files ~/Projects
miri-files /etc
```

### Desktop Entry
Installed at `~/.local/share/applications/miri-files.desktop`:
```ini
[Desktop Entry]
Name=Miri Files
Comment=Modern developer-first file explorer
Exec=/home/mirimomekiku/.local/bin/miri-files %U
Icon=system-file-manager
Terminal=false
Type=Application
Categories=System;FileManager;Utility;
Keywords=files;explorer;directory;folder;
MimeType=inode/directory;
```
