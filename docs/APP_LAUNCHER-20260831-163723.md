## 1. Executive Summary & Architecture Overview

`app-launcher` is a macOS Spotlight / Raycast-style global application launcher, command palette, and calculation engine built for Linux with **Aylur's GTK (Astal / AGS)**. It gives developers instant keyboard-first access to installed applications, terminal commands, inline mathematical calculations, and web search directly via global Hyprland keybindings (`Super + Space`).

### Core Architectural Principles
1. **Centered Floating Modal**: Renders as an ultra-fast, centered floating card (`620x420`) with instant auto-focus on invocation.
2. **Desktop Application Discovery**: Automatically queries the FreeDesktop `.desktop` database using `Gio.AppInfo.get_all()` to resolve native application names, icons, executables, categories, and descriptions.
3. **Usage Frequency Weighting**: Tracks app launch frequency in `~/.config/miri-shell/app-frequency.json` to prioritize the user's most frequently used tools at the top of empty search results.
4. **Smart Prefix Parsing**:
   - Standard text: Fuzzy app search.
   - `>` or `$`: Terminal command execution in default terminal (`kitty`, `alacritty`, `foot`).
   - `=` or math expressions (`25 * 4`, `sqrt(144)`): Real-time evaluated calculations with one-key clipboard copying (`wl-copy`).
   - `?` or `g:`: Instant Google / web search in default browser (`xdg-open`).
5. **Keyboard-Only Operation**: Fully navigable with `↑`, `↓`, `Tab`, `Enter`, and `Escape`.
6. **Unified Top-Bar Theming**: Built using the exact design tokens and typography of `miri-shell/top-bar` (`#18191c` charcoal, `#22242e` cards, `#437bf6` accents, and shadowless flat surfaces).

## 3. Detailed Component Breakdown

### 3.1 Spotlight Modal Window (`widget/Spotlight.tsx`)
- **Container (`.SpotlightWindow`)**: Transparent top-level GTK window hosting the centered `.SpotlightCard` container.
- **Header Search Bar (`.spotlight-search-header`)**:
  - Prominent Lucide `search` icon.
  - Large text input (`.spotlight-entry`) with automatic 50ms focus grab on window instantiation.
  - Ephemeral clear button (`search-clear-btn`) with Lucide `x` icon when text is entered.
- **Scrollable Results List (`.results-scrollable`)**:
  - Dynamically renders results using `createRoot((dispose) => ...)` to ensure zero tracking context warnings and no memory leaks.
  - Each item button displays:
    - Native desktop application icon or category-specific Lucide glyph.
    - Application title with bold high-contrast styling (`#ffffff`).
    - Subtitle / comment text in muted gray (`#9399b2`).
    - Return key badge (`↵ Return`) on the active/selected row.
  - Empty state with guidance on prefix shortcuts.
- **Footer Shortcuts Bar (`.spotlight-footer`)**:
  - Visual keyboard legend displaying: `[ ↵ Open ]`, `[ ↑↓ Navigate ]`, `[ > Terminal ]`, `[ ? Web ]`, and `[ esc Close ]`.
- **Keyboard Event Listener**:
  - `Escape`: Invokes `app.quit()` to dismiss launcher.
  - `Down` / `Tab`: Calls `Apps.selectNext()`.
  - `Up`: Calls `Apps.selectPrev()`.
  - `Enter` / `KP_Enter`: Calls `Apps.launchSelected()`.

## 4. Backend Services Breakdown

### 4.1 Application Service (`service/apps.ts`)
- **Desktop Application Discovery**:
  ```ts
  const rawApps = Gio.AppInfo.get_all()
  for (const app of rawApps) {
    if (!app.should_show()) continue
    const name = app.get_name()
    const description = app.get_description() || app.get_executable()
    const iconName = app.get_icon()?.to_string() || "application-x-executable"
    ...
  }
  ```
- **Frequency Weighting & Persistence**:
  - App launch counts are stored in `~/.config/miri-shell/app-frequency.json`.
  - Results are sorted by launch frequency (`countB - countA`), ensuring top apps are accessible with 0 typing.
- **Smart Result Dispatcher**:
  - If query is empty: Returns top 8 frequent apps.
  - If math expression detected: Returns calculation card with copy action.
  - If `>` or `$`: Returns terminal execution action.
  - If `?` or `g:`: Returns web search action.
  - Otherwise: Performs multi-field fuzzy matching against app name, executable path, and description.

### 4.2 Math Calculation Engine (`service/calc.ts`)
- **Expression Evaluator**:
  - Supports standard arithmetic operators: `+`, `-`, `*`, `/`, `%`, `^`.
  - Supports trigonometric & mathematical functions: `sqrt`, `sin`, `cos`, `tan`, `abs`, `log`, `ln`.
  - Supports mathematical constants: `pi`, `PI`, `e`.
  - Formats clean decimal output without trailing zeros.

## 6. Hyprland Keybinding Integration

Bind the launcher to `Super + Space` (Spotlight hotkey) in `~/.config/hypr/hyprland.conf`:

```ini
# macOS Spotlight / Raycast Global App Launcher
bind = $mainMod, SPACE, exec, ~/.local/bin/miri-launcher
```

## 7. Build, Run & Standalone Deployment

### Running in Development
```bash
cd app-launcher
npm run dev
```

Or from root repository:
```bash
npm run dev:launcher
```

### Standalone Executable Binary
Bundle standalone JavaScript binary into `dist/miri-launcher`:
```bash
npm run bundle
```

### System Launcher Wrapper
Installed at `~/.local/bin/miri-launcher`:
```bash
miri-launcher
```
