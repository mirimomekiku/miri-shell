## 1. Executive Summary & Architecture Overview

`file-explorer` is a standalone, lightweight, modern desktop file manager built using **Aylur's GTK (Astal / AGS)**. Designed specifically for developers and power users on Wayland / Hyprland compositors, it matches the dark charcoal, flat aesthetic of `miri-shell`'s top-bar while providing instant filesystem navigation, collapsible pinned quick-access bookmarks, responsive grid and list views, and rich developer workflow shortcuts.

### Core Architectural Principles
1. **Self-Contained Module**: All explorer components, services, and SCSS stylesheets reside strictly within `./file-explorer/`.
2. **Synchronous Gio Enumeration**: Uses synchronous `Gio.File.enumerate_children()` for sub-millisecond local folder parsing without async event loop overhead.
3. **Bounded Resizable Sidebar (`Gtk.Paned`)**: Left sidebar and right content area are partitioned via native `Gtk.Paned`, constrained between `140px` and `320px` to prevent viewport distortion.
4. **Persistent Pinned Folders**: Developer bookmarks are stored in `~/.config/miri-shell/pinned-folders.json` with an expandable/collapsible sidebar section.
5. **Zero "Tracking Context" Leaks**: All dynamic GTK container renders (`$={(self) => ...}`) are encapsulated inside `createRoot((dispose) => ...)` scopes, guaranteeing zero GJS memory leaks or reactive lifecycle warnings.
6. **Developer-First Context Menu**: Right-clicking any item provides instant actions to launch **Antigravity IDE**, **VS Code**, **Terminal**, **LazyGit**, copy paths (`wl-copy`), and move items to trash.
7. **Unified Miri Theme**: 100% color-synchronized with `top-bar` (`#18191c` background, `#22242e` cards, `#437bf6` accent blue, and shadowless flat design).

## 3. Detailed Component Breakdown

### 3.1 Main Window (`widget/Window.tsx`)
- **Container**: `window.ExplorerWindow` with default dimensions `920x600`.
- **Resizable Layout (`Gtk.Paned`)**:
  - Implements `new Gtk.Paned({ orientation: Gtk.Orientation.HORIZONTAL, position: 200 })`.
  - Connects to `notify::position` signal to clamp divider position between `140px` (min) and `320px` (max).
  - Left pane (`pack1`): `<Sidebar />` (`resize=false`, `shrink=false`).
  - Right pane (`pack2`): `<FileView />` (`resize=true`, `shrink=false`).
- **Footer Status Bar (`.StatusBar`)**:
  - Item count indicator (e.g. `24 items`).
  - Ephemeral feedback text for copy/pin actions (`Copied path to clipboard`).
  - Active path label with middle ellipsize (`.../Projects/miri-shell`).
- **Keyboard Accelerators**:
  - `Escape`: Clear active search filter.
  - `Ctrl + H`: Toggle hidden dotfiles.
  - `Ctrl + R` / `F5`: Force refresh directory.
  - `Alt + Left`: History Back.
  - `Alt + Right`: History Forward.
  - `Alt + Up` / `Backspace`: Navigate to Parent Directory.

---

### 3.2 Header Navigation Bar (`widget/Header.tsx`)
- **Navigation Controls**:
  - Back (`arrow-left`), Forward (`arrow-right`), Up (`arrow-up`), Refresh (`rotate-cw`).
  - Dynamic button opacity styling based on `FS.canGoBack()` and `FS.canGoForward()`.
- **Interactive Breadcrumbs Bar (`.breadcrumbs-scrollable`)**:
  - Styled as a dark horizontal pill (`#14151a`, `border-radius: 9999px`).
  - Intelligently collapses `$HOME` path into clean `~` root chip.
  - Clicking any breadcrumb segment navigates directly to that parent folder.
- **Search Entry (`.search-box`)**:
  - Real-time text filtering against directory items.
- **Action Buttons**:
  - Grid / List view toggle button (`layout-grid` / `list`).
  - Hidden files toggle (`eye` / `eye-off`).
  - Terminal launcher button (`terminal`).

---

### 3.3 Collapsible Sidebar (`widget/Sidebar.tsx`)
- **PINNED / QUICK ACCESS Section**:
  - Interactive header button with Lucide `chevron-down` / `chevron-right` toggle.
  - Animated `Gtk.Revealer` (`transitionType=SLIDE_DOWN`).
  - Lists user-pinned directories with contextual folder icons.
  - Hovering reveals instant unpin button (`✕`).
  - Right-click brings up unpin and open in terminal options.
- **PLACES Section**:
  - Standard user shortcuts: **Home**, **Downloads**, **Documents**, **Pictures**, **Music**, **Videos**, and **Root System (`/`)**.
  - Active path highlighting (`.active` pill styling `#2b2f3e` with `#437bf6` accent).

---

### 3.4 File & Folder Content View (`widget/FileView.tsx`)
- **Dual View Modes**:
  1. **Grid View (`Gtk.FlowBox`)**:
     - Homogeneous square cards with 38px folder/file Lucide icons.
     - Filename wrapped and centered.
     - Folder sizes are automatically omitted; file sizes displayed in subtle muted text.
  2. **List View (`Gtk.Box`)**:
     - Dense row layout with Name, Size, and Date Modified columns.
- **Robust Double-Click Navigation**:
  - Implements timestamp delta tracking (`now - lastClickTime < 450ms`) to guarantee 100% double-click detection across all Wayland compositors.
- **Developer Context Menu**:
  - **Open File / Open Folder**
  - **Open with Antigravity IDE** (`agy` / `antigravity`)
  - **Open with VS Code** (`code` / `codium`)
  - **Open in Terminal** (`kitty` / `alacritty` / `foot`)
  - **Open in LazyGit** (for Git repositories)
  - **Pin to Sidebar / Unpin from Sidebar**
  - **Copy Full Path** (`wl-copy`)
  - **Move to Trash** (`Gio.File.trash_async`)

## 4. Backend Services & State Management

### 4.1 Filesystem Service (`service/fs.ts`)
- **Synchronous Enumerator**:
  ```ts
  const enumerator = dir.enumerate_children("standard::*,time::*", Gio.FileQueryInfoFlags.NONE, null)
  while ((info = enumerator.next_file(null)) !== null) { ... }
  ```
- **State Properties (`gnim`)**:
  - `currentPath`: Accessor for active directory.
  - `items`: Raw array of `FileItem` objects.
  - `filteredItems`: Computed array applying search filters, hidden file rules, and folder-first alphabetical sorting.
  - `pinned`: Pinned directories loaded from and saved to `~/.config/miri-shell/pinned-folders.json`.
  - `viewMode`: `"grid"` | `"list"`.
  - `showHidden`: Boolean toggle.

### 4.2 MIME & File Extension Icon Mapper
- Automatically resolves optimal Lucide glyphs:
  - **Office / Documents**: `.doc`, `.docx`, `.pdf`, `.txt`, `.md`, `.rtf` → `Lucide["file-text"]`
  - **Spreadsheets**: `.xlsx`, `.csv`, `.tsv`, `.ods` → `Lucide["file-spreadsheet"]`
  - **Code**: `.ts`, `.py`, `.rs`, `.go`, `.json`, `.yaml`, `.html`, `.css` → `Lucide["file-code"]`
  - **Images**: `.png`, `.jpg`, `.webp`, `.svg`, `.gif` → `Lucide["image"]`
  - **Audio & Video**: `.mp3`, `.flac`, `.mp4`, `.mkv` → `Lucide["music"]` / `Lucide["video"]`
  - **Archives**: `.zip`, `.tar.gz`, `.7z`, `.deb`, `.rpm` → `Lucide["archive"]`
  - **Binaries / Scripts**: `.bin`, `.appimage`, `.sh`, `.exe` → `Lucide["terminal"]`

## 6. Build, Run & Standalone Deployment

### Running in Development
```bash
cd file-explorer
npm run dev
```

### Standalone Executable Binary
Bundle standalone JavaScript binary into `dist/miri-files`:
```bash
npm run bundle
```

### System Launcher Wrapper
Installed at `~/.local/bin/miri-files`:
```bash
miri-files
# or open specific path:
miri-files ~/Projects
```
