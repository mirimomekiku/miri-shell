## 1. Executive Summary & Architecture Overview

`app-launcher` is a centered floating Spotlight / Raycast modal window. It integrates FreeDesktop `.desktop` application discovery (`Gio.AppInfo`), usage frequency ranking (`~/.config/miri-shell/app-frequency.json`), real-time inline math evaluation, terminal command execution (`>`), and web search (`?`), equipped with `Alt+1..8` instant numeric accelerators.

## 3. Smart Prefixes & Interactive Modes

| Prefix / Mode | Trigger Syntax | UI Badge | Execution Action |
|---|---|---|---|
| **App Search** | Standard text (e.g. `code`, `brave`) | Category Pill (`Dev`, `Media`, `System`) | Launches application with frequency weighting |
| **Terminal Mode** | `> command` or `$ command` | `[ 💻 Terminal ]` (`#a6e3a1`) | Spawns command in terminal (Ptyxis, Kitty, Foot, Alacritty) |
| **Calculator** | Expression (e.g. `25 * 4`, `= 500 / 2`) | `[ 🧮 Calculator ]` (`#58a6ff`) | Evaluates result in real time; `Enter` copies to clipboard |
| **Web Search** | `? query` or `g: query` | `[ 🌐 Web Search ]` (`#f9e2af`) | Opens Google search query in default web browser |
