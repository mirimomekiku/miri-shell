## 1. Executive Summary & Architecture Overview

`setup-launcher` is a graphical developer environment onboarding wizard built using **Astal GTK3** for Fedora Linux and Hyprland. It enables engineers to select and install all required web, backend, mobile, AI agent, and terminal tools in one automated flow with real-time log output and progress tracking.

### Core Architectural Features
1. **Interactive Granular Package Checklist**: Users can select one, several, or all tools using individual checkboxes, category pill filters, or global "Select All" / "Deselect All" actions.
2. **Live System Inspection**: Automatically queries system binaries on startup (`which node`, `which docker`, `which code`, etc.) and marks existing tools with green `[ Installed ]` badges.
3. **Sequential Installation Pipeline (`Gio.Subprocess`)**: Executes installation commands sequentially, capturing stdout and stderr in real time and streaming them to a monospace log terminal.
4. **Impeccable Theme Parity**: Harmonized with `top-bar`, `file-explorer`, and `app-launcher` (`#18191c` charcoal, `#22242e` cards, `#437bf6` accents, Lucide glyphs).

## 4. Build, Run & Standalone Deployment

### Running in Development
```bash
cd setup-launcher
npm run dev
```

Or from repository root:
```bash
npm run dev:setup
```

### Standalone Executable Binary
Bundle standalone JavaScript binary into `dist/miri-setup`:
```bash
cd setup-launcher
npm run bundle
```

### Standalone CLI Launcher
```bash
miri-setup
```

### Desktop Entry
Installed at `~/.local/share/applications/miri-setup.desktop` for system application menus.
