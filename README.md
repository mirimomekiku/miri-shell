# Miri Shell — Hyprland Floating Pill Top Bar

A modern, fast, floating pill top bar and drop-down ecosystem for Linux (Hyprland) built with **AGS (Astal 3.0)**, TypeScript, SCSS, and **Lucide Icons**.

## 🚀 Quick Start on Fresh Hyprland

Initialize everything and enable persistent autostart across reboots:

```bash
chmod +x init-hyprland.sh
./init-hyprland.sh
```

## 📂 Project Structure

- `top-bar/`: Contains all Top Bar widgets, services, and SCSS styles.
- `init-hyprland.sh`: Automated environment initializer and Hyprland autostart configurator.
- `docs/`: Comprehensive architecture and handoff documentation (`docs/TOPBAR-20260831-142801.md`).
